# Nethernet Desktop native packages

The desktop suite is packaged independently from the tunnel CLI. Existing CLI
installers and the CLI `v*` release workflow remain unchanged.

## Linux

The native release workflow builds:

- AppImage
- Debian/Ubuntu `.deb`
- Arch Linux `.pkg.tar.zst`

The Debian and Arch packages declare GTK 4 and WebKitGTK 6 runtime dependencies.
The AppImage is generated by the Wails AppImage packager; host graphics and
desktop integration libraries may still be required.

## Windows

The release workflow creates a per-user NSIS installer. It does not request
administrator privileges and uses Wails' WebView2 bootstrapper flow. The
Microsoft Edge WebView2 Runtime is required to run the application.

## Tunnel engine

The desktop app deliberately installs and updates the matching
`nethernet-client` engine through its Settings screen using the existing
SHA-256-verified updater. The native installers do not overwrite a separately
installed CLI or its configuration.

## Local packaging

Install Go 1.26+, Wails CLI v3.0.0, and the platform build dependencies.
From this directory run:

- Linux: `wails3 task linux:package`
- Windows: `wails3 task windows:package`

Linux packaging requires GTK 4, WebKitGTK 6.0, AppImage tooling and nfpm.
Windows packaging requires NSIS and the Wails WebView2 bootstrapper generator.
